#fassung 12
請把這段說明讀一遍。它解釋這個程式在你的電腦上做什麼、什麼會離開你的電腦，以及
Windows 為什麼可能對它發出警告。


它在你的電腦上做什麼

  從遊戲讀取遙測。
      Forza Horizon 6 可以透過 UDP 把自己的遙測資料傳送到你自己的電腦。這需要你自
      己在遊戲的「設定 > 抬頭顯示器與遊戲」中開啟。程式在 127.0.0.1（你自己的電
      腦，而不是網路）上監聽，並把這些資料用於圈速差值、即時地圖、你的圈速紀錄和控
      制器震動。只有當你在程式視窗頂端把它切換到「Xbox / 第二台電腦」時，它才會改
      為在你的網路上監聽，讓 Xbox 或另一台電腦能連線到它。如果 Windows 防火牆封鎖
      了這一點，Xbox 面板中的一個按鈕會新增一條只針對這個 UDP 連接埠的規則——只有
      在你按下它時才會新增，而且 Windows 會先徵求你的許可。

  讀取遊戲在螢幕上顯示的內容。
      為了知道「報名賽事」畫面提供哪些賽道、車輛選單中選取了哪輛車、你正在檢視的
      「我的車輛」頁面上有哪些車，以及車輛的調校清單中哪個調校裝在這輛車上，程式會
      擷取遊戲視窗的畫面，並用 Windows 內建的文字辨識功能讀取其中的文字。這一切都
      在你的電腦上進行；畫面不會傳送到任何地方。在「Xbox / 第二台電腦」模式下，它
      會改為從你選擇的來源擷取這些畫面：擷取卡、OBS、Xbox Remote Play 視窗、
      Discord、瀏覽器中的直播，或一個直播網址。此時 Windows 會在被擷取的視窗周圍畫
      出黃色外框。

  從遊戲的存檔資料夾讀取你下載的調校——唯讀。
      Tunes 分頁會計算它們的數量，並顯示哪些調校沒有被任何車使用。存檔資料夾不會因
      此有任何變更。

  讀取排行榜和你的拍賣——透過在遊戲中按鍵。
      在「掃描排行榜」分頁，程式會把遊戲選單操作到你勾選的排行榜，並從螢幕上讀取。
      在「拍賣行」分頁，它可以把遊戲帶到「我的出價」並讀取你的拍賣；該清單只留在這
      台電腦上。它從不出價。兩者都會在按 Alt+Tab、Pause 鍵或「停止」時停下。

  讓你的控制器震動——這會讓它的電池更快耗盡。
      當 Forza 執行並傳送遙測時，程式會驅動你控制器的震動：輪胎抓地力會變成震感，
      車輪鎖死會變成一下短促的嗡嗡震動。這項功能一開始就是開啟的。無線控制器在震動
      時，電量會明顯更快耗盡；你在 藍圖編輯器 中把震動設得越強、越快（頻率越
      高），耗電就越多。要關閉它，請在 藍圖編輯器 中取消勾選
      「圖表輸出已啟用」；程式會記住這個設定。

  監看按鍵。
      只是為了偵測快速鍵——F10 會在自由漫遊中設定起點／終點線。它只檢查這些特定的
      鍵是否被按下。它不會記錄你輸入的內容，任何地方都沒有按鍵記錄。

  在遊戲上方繪製疊加層。
      圈速差值、地圖、車輛備註和對手面板都是繪製在 Forza 上方的獨立視窗。當某一圈
      超越網站上的成績時，會出現約五秒鐘的簡短慶祝，帶有彩色紙花和音效；你可以在
      圈速差值 HUD 分頁中關閉它。

  記錄你的圈速——存在你的磁碟上。
      時間、位置和速度會寫入程式自己的資料夾，讓它能顯示你與自己最佳成績之間的差
      值。只有超越排行榜的一圈才會被傳送出去——見下文。


什麼會離開你的電腦

  程式連線到伺服器只為以下六件事：

      1. 詢問車輛評分是否比你現有的更新，如果是，就取得它們。
      2. 詢問這個程式是否有更新的版本。
      3. 在你按下更新按鈕時，下載那個新版本。
      4. 提交一個「超越」排行榜的圈速——預設為開啟，除非你把它關閉。
      5. 為 車輛收藏 分頁取得所有車輛的清單及各自的取得方式——最多每十二小
         時一次，而且只在該分頁開啟時。它不傳送任何內容；你擁有哪些車只留在這台電
         腦上。
      6. 傳送你在「掃描排行榜」分頁掃描的排行榜：每列的名次、時間、車輛、PI、
         驅動方式、變速箱和輔助，以及賽道、等級、掃描時間和這台電腦的雜湊識別碼——不
         含玩家代號。只要勾選了「每完成一個排行榜就上傳」（預設已勾選）且提交已開啟，
         每完成一個排行榜就會傳送。

  關於第 4 點：只有當一圈比同一輛車在該賽道與該級別的排行榜最佳成績更快，而且比你
  之前為此傳送過的任何成績都更快時，才會傳送。傳送的內容包括：車輛、賽道、級別、時
  間，以及這一圈的「完整」遙測——也就是遊戲在這一圈中傳送的每一個封包：位置與方
  向、速度、你的油門、煞車、離合器與轉向、檔位、引擎，以及每個車輪的輪胎溫度、滑移
  與懸吊——讓伺服器能檢查成績是否真實，也讓人能檢視看起來有問題的圈速。此外還會傳
  送這台電腦的一個經過雜湊處理的識別碼，以便封鎖濫用——如果你在 Rivals 分頁中設定
  了玩家代號，也會傳送你的玩家代號。玩家代號不是必要的：沒有它，圈速仍會傳送，並在
  網站上以臨時玩家名稱顯示。你之後設定的玩家代號會在你所有的圈速上取代這個臨時名
  稱，包括先前的圈速；之後清空該欄位則會保留最後一個名稱。伺服器在顯示一圈之前會再
  次檢查它。要關閉此功能，請在 Rivals 分頁中關閉
  （「當我的圈速超過排行榜時提交」），或在 config/overlay.json 中設定
  "submit_laps": false。

  從此版本起你提交的圈速也會連同該遙測一起公開：在網站上，你的成績旁邊，任何人
  都可以下載該圈的完整遙測（CSV 表格和原始檔案），研究它是怎麼跑的。此前提
  交的圈速保持私密，只用於核實成績。

  超越了排行榜、但當下無法傳送的圈速——提交已關閉、處於離線狀態，或伺服器沒有回
  應——會保存在這台電腦上，等這些情況都恢復正常後再傳送，即使是幾週以後。傳送之
  前，它會再與當天的排行榜比對一次，如果已經不再更快，就會被捨棄。因此，重新開啟提
  交時，也會傳送你在關閉期間跑出的最佳圈速。Rivals 分頁中的「捨棄等待中的圈速」則
  會刪除它們，而不是傳送。

  除此之外不會傳送任何內容。你的一般圈速不會上傳。你的調校不會上傳。沒有帳號，也沒
  有需要登入的地方。

  因為你的電腦會提出這些詢問，伺服器會看到某個安裝在詢問——對任何會檢查更新的程式
  來說，這都是無法避免的。我們會對此計數，以便大致了解有多少人在使用；識別碼會用一
  個只保存在伺服器上、並在 40 天後刪除的密鑰進行雜湊處理。如果你介意，請在
  config/overlay.json 中設定 "offline": true，程式就再也不會連線到伺服器——之後它
  完全依靠下載時附帶的資料執行，除了更新以外，其他一切都照常運作。


它如何自我更新

  當你按下更新按鈕時，程式會下載一個 ZIP，驗證其發行者的簽章，解壓縮後取代自己的檔
  案。未經發行者簽章的套件會被拒絕。在此期間會出現一個小的主控台視窗——這個視窗是
  刻意顯示的，讓你能看到什麼正在被取代。你的設定資料夾會被保留。

  不會安裝任何東西。不會寫入任何內容到 Windows 登錄檔。刪除資料夾，程式就沒了。


為什麼 Windows 可能把它稱為木馬

  Windows Defender 可能會把這個程式回報為 Trojan:Win32/Bearfoos.A!ml 並封鎖它。後
  綴「!ml」表示這並不是與任何已知惡意軟體的比對結果——而是機器學習模型對一個它從
  未見過的檔案所做的猜測。

  它之所以這樣猜測，是因為這個程式沒有程式碼簽章，幾乎還沒有人擁有它，而且它會做上
  面列出的兩件事：取代自己的檔案、從網際網路下載。這些正是該模型被訓練去懷疑的行
  為。

  每個版本在發布前都會經過掃描，下載頁面也會顯示總和檢查碼，讓你可以驗證你拿到的檔
  案就是當初建置出來的那個檔案。如果你不願意就這樣相信，就不要執行它——這是一個正
  當的選擇，這個程式也不會為此糾纏你。


捷徑（如果你需要）

  在這段文字下方，你可以選擇建立桌面捷徑、開始功能表項目，以及讓程式隨 Forza 啟
  動。除非你勾選，否則這三項都是關閉的；這三項都只是某個資料夾裡的一個 .lnk 檔案，
  之後你可以刪除其中任何一個，而不會動到程式本身。

  「隨 Forza 啟動」會把程式放進你的 Windows 啟動資料夾。從登入開始，它會隱藏在通知
  區域中等待，並在 Forza 啟動時開啟（最小化）；遊戲結束後它會回到通知區域。沒有系
  統管理員權限時，Windows 不允許一個程式在另一個程式啟動時隨之啟動——而在通知區域
  中等待不需要系統管理員權限，幾乎沒有任何負擔。關閉視窗後它仍會繼續等待；在圖示上
  按右鍵即可結束。主視窗右上角的「隨 Forza 啟動」按鈕可以開啟和關閉這項功能。

  Windows 不允許程式把自己釘選到工作列——自 Windows 10 版本 1607 起，這項操作只保
  留給你自己，要繞過它就必須偽造登錄檔中的總和檢查碼。這個程式不會這樣做。請勾選開
  始功能表項目，然後在它上面按右鍵，選擇「釘選到工作列」。
