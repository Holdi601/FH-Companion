#fassung 10
请把这段说明读一遍。它解释这个程序在你的电脑上做什么、什么会离开你的电脑，以及
Windows 为什么可能对它发出警告。


它在你的电脑上做什么

  从游戏读取遥测。
      Forza Horizon 6 可以通过 UDP 把自己的遥测数据发送到你自己的电脑上。这需要你
      自己在游戏的“设置 > 抬头显示与游戏”中开启。程序在 127.0.0.1（你自己的电
      脑，而不是网络）上监听，并把这些数据用于圈速差值、实时地图、你的圈速记录和手
      柄振动。只有当你在程序窗口顶部把它切换到“Xbox / 第二台电脑”时，它才会改为
      在你的网络上监听，以便 Xbox 或另一台电脑能连接到它。如果 Windows 防火墙阻止
      了这一点，Xbox 面板中的一个按钮会添加一条只针对这个 UDP 端口的规则——只在你
      按下它时才会添加，而且 Windows 会先征求你的许可。

  读取正在运行的游戏的内存——只在你按下按钮时。
      你车上装了哪些零件，以及哪个调校装在哪辆车上，这些都不在遥测里。它们存放在游
      戏保存在自己内存中的一个小型数据库里。为了显示这些信息，程序以只读方式打开
      Forza 进程并搜索这块内存。

      它只“读取”。它从不向游戏写入任何内容，也从不修改游戏里的任何东西。只有当你
      在 Tuning、Tunes、车辆备注 或 车辆收藏 标签页中按下对应的按钮时，它才
      会这样做。如果你从不按这些按钮，游戏的内存就永远不会被触碰。若要彻底排除这一
      点，请取消勾选窗口顶部的“读取游戏内存”：这样程序会改为从屏幕上了解你的车辆
      及其调校（见下文）。

  读取游戏在屏幕上显示的内容。
      为了知道赛事报名界面提供哪些赛道、车辆菜单中选中了哪辆车、你正在查看的“我的
      车辆”页面上有哪些车，以及车辆的调校列表中哪个调校装在这辆车上，程序会拍下游
      戏窗口的画面，并用 Windows 内置的文字识别功能读取其中的文字。这一切都在你的
      电脑上进行；画面不会被发送到任何地方。在“Xbox / 第二台电脑”模式下，它会改
      为从你选择的来源拍下这些画面：采集卡、OBS、Xbox Remote Play 窗口、Discord、
      浏览器中的直播，或一个直播地址。此时 Windows 会在被捕获的窗口周围画出一个黄
      色边框。

  从游戏的存档文件夹读取你下载的调校——只读。
      Tunes 标签页会统计它们的数量，并显示哪些调校没有被任何车使用。存档文件夹不会
      因此发生任何改变。

  在游戏中删除调校——只在你启动时。
      在 Tunes 标签页中，你可以让程序通过游戏自己的菜单删除未使用的调校。这时它会
      切换到游戏并自己按键。它会先询问你，提供一次不删除任何东西的试运行，从不删除
      装在车上的调校，并且在按下 Alt+Tab 或 Pause 键时停止。

      这也是杀毒软件不信任这个程序的最大原因：读取其他进程的内存，正是作弊程序或密
      码窃取程序会做的事。而在这里，它读取的是一款单人赛车游戏中你自己车辆的零件
      列表。

  让你的手柄振动——这会让它的电池更快耗尽。
      当 Forza 运行并发送遥测时，程序会驱动你手柄的振动：轮胎抓地力会变成震感，车
      轮抱死会变成一下短促的嗡嗡振动。这项功能一开始就是开启的。无线手柄在振动时，
      电量会明显更快耗尽；你在 蓝图编辑器 中把振动设得越强、越快（频率越
      高），耗电就越多。要关闭它，请在 蓝图编辑器 中取消勾选
      “图表输出已启用”；程序会记住这一设置。

  监视按键。
      只是为了捕捉快捷键——F10 会在自由漫游中设置起点/终点线。它只检查这些特定的
      键是否被按下。它不会记录你输入的内容，任何地方都没有按键记录。

  在游戏上方绘制叠加层。
      圈速差值、地图、车辆备注和对手面板都是绘制在 Forza 上方的独立窗口。当某一圈
      超过网站上的成绩时，会出现一段约五秒钟的简短庆祝，带有彩色纸屑和声音；你可以
      在 圈速差值 HUD 标签页中关闭它。

  记录你的圈速——保存在你的磁盘上。
      时间、位置和速度会被写入程序自己的文件夹，这样它就能显示你与自己最佳成绩之间
      的差值。只有超过排行榜的一圈才会被发送出去——见下文。


什么会离开你的电脑

  程序联系服务器只为以下五件事：

      1. 询问车辆评分是否比你现有的更新，如果是，就获取它们。
      2. 询问这个程序是否有更新的版本。
      3. 在你按下更新按钮时，下载那个新版本。
      4. 提交一个“超过”排行榜的圈速——默认开启，除非你把它关闭。
      5. 为 车辆收藏 标签页获取所有车辆的列表以及各自的获取方式——最多每十
         二小时一次，并且只在该标签页打开时。它不发送任何内容；你拥有哪些车只保留
         在这台电脑上。

  关于第 4 点：只有当一圈比同一辆车在该赛道和该级别上的排行榜最佳成绩更快，并且比
  你之前为此发送过的任何成绩都更快时，才会发送。发送的内容包括：车辆、赛道、级别、
  时间，以及这一圈的“完整”遥测——也就是游戏在这一圈中发送的每一个数据包：位置和
  朝向、速度、你的油门、刹车、离合和转向、挡位、引擎，以及每个车轮的轮胎温度、滑移
  和悬挂——这样服务器就能检查成绩是否真实，也能让人查看看起来有问题的圈速。此外还
  会发送这台电脑的一个经过哈希处理的标识符，以便阻止滥用——如果你在 Rivals 标签页
  中设置了玩家代号，也会发送你的玩家代号。玩家代号不是必需的：没有它，圈速仍会发
  送，并在网站上以临时玩家名显示。你之后设置的玩家代号会在你所有的圈速上替换这个临
  时名字，包括之前的圈速；之后清空该栏会保留最后一个名字。服务器在显示一圈之前会再
  次检查它。要关闭此功能，请在 Rivals 标签页中关闭
  （“当我的圈速超过排行榜时提交”），或在 config/overlay.json 中设置
  "submit_laps": false。

  从此版本起你提交的圈速也会连同该遥测一起公开：在网站上，你的成绩旁边，任何人
  都可以下载该圈的完整遥测（CSV 表格和原始文件），研究它是怎么跑的。此前提
  交的圈速保持私密，只用于核实成绩。

  超过了排行榜、但当时无法发送的圈速——提交已关闭、处于离线状态，或服务器没有响
  应——会保存在这台电脑上，等这些情况都恢复正常后再发送，即使是几周以后。发送之
  前，它会再与当天的排行榜比较一次，如果已经不再更快，就会被丢弃。因此，重新开启提
  交时，也会发送你在关闭期间跑出的最佳圈速。Rivals 标签页中的“丢弃等待中的圈速”
  则会删除它们，而不是发送。

  除此之外不会发送任何内容。你的普通圈速不会上传。你的调校不会上传。没有账号，也没
  有需要登录的地方。

  因为你的电脑会提出这些询问，服务器会看到某个安装在询问——对任何会检查更新的程序
  来说，这都是无法避免的。我们会对此计数，以便大致了解有多少人在使用；标识符会用一
  个只保存在服务器上、并在 40 天后删除的密钥进行哈希处理。如果你介意，请在
  config/overlay.json 中设置 "offline": true，程序就再也不会联系服务器——之后它完
  全依靠下载时附带的数据运行，除了更新以外，其他一切都照常工作。


它如何自我更新

  当你按下更新按钮时，程序会下载一个 ZIP，验证其发布者的签名，解压后替换自己的文
  件。未经发布者签名的包会被拒绝。在此期间会出现一个小的控制台窗口——这个窗口是有
  意显示的，让你能看到什么正在被替换。你的设置文件夹会被保留。

  不会安装任何东西。不会向 Windows 注册表写入任何内容。删除文件夹，程序就没了。


为什么 Windows 可能把它称为木马

  Windows Defender 可能会把这个程序报告为 Trojan:Win32/Bearfoos.A!ml 并阻止它。后
  缀“!ml”表示这并不是与任何已知恶意软件的匹配——而是机器学习模型对一个它从未见
  过的文件所作的猜测。

  它之所以这样猜测，是因为这个程序没有代码签名，几乎还没有人拥有它，而且它会做上面
  列出的三件事：读取其他进程的内存、替换自己的文件、从互联网下载。这些正是该模型被
  训练去怀疑的行为。

  每个版本在发布前都会经过扫描，下载页面也会显示校验和，让你可以验证你拿到的文件就
  是构建出来的那个文件。如果你不愿意就这样相信，就不要运行它——这是一个正当的选
  择，这个程序也不会为此纠缠你。


快捷方式（如果你需要）

  在这段文字下方，你可以选择创建桌面快捷方式、开始菜单项，以及让程序随 Forza 启
  动。除非你勾选，否则这三项都是关闭的；这三项都只是某个文件夹里的一个 .lnk 文件，
  以后你可以删除其中任何一个，而不会影响程序本身。

  “随 Forza 启动”会把程序放进你的 Windows 启动文件夹。从登录开始，它会隐藏在通知
  区域中等待，并在 Forza 启动时打开（最小化）；游戏结束后它会回到通知区域。没有管
  理员权限时，Windows 不允许一个程序在另一个程序启动时随之启动——而在通知区域中等
  待不需要管理员权限，几乎没有任何开销。关闭窗口后它仍会继续等待；右键单击图标即可
  退出。主窗口右上角的“随 Forza 启动”按钮可以开启和关闭这项功能。

  Windows 不允许程序把自己固定到任务栏——自 Windows 10 版本 1607 起，这一操作只保
  留给你自己，要绕过它就得伪造注册表中的校验和。这个程序不会这样做。请勾选开始菜单
  项，然后右键单击它，选择“固定到任务栏”。


不提供任何担保

  这是一个免费发布的业余项目，不提供任何形式的担保。它与 Microsoft、Turn 10、
  Playground Games 或 Forza Horizon 系列没有任何隶属、认可或关联关系。
