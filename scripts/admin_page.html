Builds the tool with their credentials and downloads it here. Whoever holds this file can feed data in — so send it over a channel you trust. The version with no credentials sits publicly at /download/tool and may be linked freely.

Upload password

The long password sits inside every friend package handed out, and is computed into the upload, never sent along. Rotating it is the emergency switch: every package handed out so far becomes invalid and has to be rebuilt. To cut off a single contributor instead, use contrib_keys.py revoke <name>.
